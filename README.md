# Bures Wasserstein GPCA

This repository implements Geodesic Principal Component Analysis (GPCA) in the space of SPD matrices for the Bures-Wasserstein metric. Tangent Princical Component Analysis (TPCA) is also implemented for comparison. The examples reproduce some of the experiments of the paper below. 

# References

N. Vesseron, E. Cazelles, A. Le Brigant and T. Klein, On the Wasserstein Geodesic Principal Components Analysis of probability measures. ICLR, 2026. [(pdf)](https://arxiv.org/pdf/2506.04480?)
